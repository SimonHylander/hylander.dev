## Decisions

The migration is a strangler fig: the new client takes over the legacy system route by route, while the old one keeps serving the rest.

<BuildDiagram diagram={byggdagbokenDiagram}>
<DiagramStep>

**The monolith.** Web traffic went through CloudFront to the legacy monolith: PHP on the server, Angular.js in the browser.

</DiagramStep>
<DiagramStep>

**Route-level canaries.** A CloudFront Function sends a percentage of each migrated route's traffic to the new Next.js web client. The rest stays on the monolith.

</DiagramStep>
<DiagramStep>

**A backend-for-frontend.** The native apps talk to a Node.js BFF, which aggregates their data across the microservices.

</DiagramStep>
<DiagramStep>

**One identity.** Sign-in moved to OAuth2 and OpenID Connect, using the Authorization Code flow with PKCE. Redis holds the short-lived tokens.

</DiagramStep>
</BuildDiagram>
